# Jewel Case 1.1

A big update to the look and feel, with real disc and box art, game info, Switch updates and
DLC that just work with ProsperoEden, and a smoother app throughout.

## What's new

**Cartridges and discs that look like the real thing**
- Cartridges, cards and discs are rendered from 3D models (credited in Settings > Credits).
  The SNES cartridge has the lavender-grey shell and black label of the real ones, and N64
  cartridges get more room in the carousel.
- Cartridge labels show the box art without the box's system banner and ratings.
- Discs are printed edge to edge, with the game's title logo, a thin silver rim and a clear
  hub. PS1, PS2 and GameCube discs have their system's band, and GameCube discs are the
  smaller 8 cm size.
- A scan of the real disc is used when there is one: from the LaunchBox Games Database, and
  from GameTDB for GameCube and Wii (found by the game ID in the disc image). Your own disc
  image works too.

**Game info and more art**
- The details screen shows each game's year, genre, developer, publisher, players and
  description from the LaunchBox Games Database, with an in-game screenshot behind it.
- Box art from LaunchBox for systems the libretro collection doesn't cover, such as Switch.
- The LaunchBox game list comes with the app (only the systems Jewel Case supports, about
  17 MB), so the console never downloads the whole database: only the pictures for your games.
- Covers now download over HTTPS reliably. The cover helper does its own encryption (curl
  and OpenSSL, with Mozilla's root certificates), because the console's own SSL refuses
  payloads. This also fixes libretro covers for oddly named files.

**Updates and DLC**
- Update and DLC files sit with their game instead of showing up as extra games.
- Switch with ProsperoEden (v1.005 or newer): Jewel Case lists the games in ProsperoEden's
  game files folder, and its updates and DLC are applied when the game starts. One folder,
  one copy of each file.
- Other emulators: an amber or green chip shows whether an update or DLC is installed in the
  emulator yet, and File info (Square on the details screen) lets you mark it installed.
- The game's version, from its file name, is shown on the details screen.

**Feel**
- Starting a game sends it off the screen: discs spin up, cartridges turn, both fly away.
- Turn the selected game all the way round with the right stick.
- A soft built-in rain track (your own MP3s still take over), and a low retro boop when you
  move between games and options (Settings > Menu sounds). Both are generated by Jewel Case's
  own code, nothing recorded.
- 60 fps, and a much faster details screen: no more stutter when it opens or when you turn
  the game.
- Only L1 / R1 change system now; the D-pad's up and down no longer do.

**Settings**
- Games folder: keep your roms on internal storage, extended storage or a USB drive.
  Create system folders makes them on the drive you picked.
- Menu sounds on/off; Credits lists every model, art source and library.

## Install

1. Download `PPSA75837.zip` below.
2. Extract it and copy the `PPSA75837` folder to `/data/homebrew/` on your PS5 (to update,
   copy it over your existing one).
3. Install it with ShadowMountPlus and start Jewel Case from the home screen.

Needs an ELF loader on port 9021 (etaHEN's, or a standalone one). Tested on firmware 13.42.
Your settings, favorites and covers in `/data/jewelcase` are kept. See `README.txt` in the app
folder for folders, controls and troubleshooting.

## Known limitations

- PSXS5 (PS1) and PS5SX2 (PS2) don't accept a game at launch yet, so they open their own game
  list.
- Jewel Case can't install updates or DLC into an emulator itself; ProsperoEden doesn't need
  it, other emulators install them from their own menu.
